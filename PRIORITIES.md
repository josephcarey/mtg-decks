# Deckbuilding Priorities & Preferences

Owner's standing preferences. The tooling and any agent should apply these by default when suggesting cards, discovering candidates, or evaluating decks. Individual decks may override, but call it out when they do.

## Power & banned-ish
- **Game Changers:** avoid by default. Allow one only when it is *essential* to the deck's core strategy — not as a generic power upgrade. Keep leaning on the Scryfall `game_changer` flag to flag them.
- **"Non-games" — avoid across all decks:** infinite combos, stax / resource denial, mass land destruction, extra-turn chains — anything where opponents don't get to play. The only exception is a single deck whose *explicit whole point* is that theme (e.g. one dedicated MLD deck). Such effects must never leak into any other deck.

## Budget
- Pod proxies freely, so price is **not a hard barrier**.
- Still keep a **mid-budget discipline**: a few (~3–4) genuinely high-impact expensive cards per deck are fine; do **not** pay up for marginal upgrades that are ~95% as good as a cheaper option (classic example: skip the pricey land when a cheap one does the job).
- **Budget-friendliness is a positive**, especially when a cheaper choice increases set coherence / theme — worth it even if strictly weaker.

## Theme vs. power
- **Theme-first**, deck-dependent: somewhere between "on-theme beats generically stronger" and "strong thematic core with goodstuff filling the gaps." Never pure goodstuff.
- Being **on-theme matters more than being precisely competitive** — e.g. a stompy deck running *zero* interaction is fine if that's the identity.
- Loves a **clever sub-theme** layered onto a deck.

## Interaction & protection
- Value of removal/protection **scales with the commander's cost and essentiality**:
  - Cheap, easily-recast commanders → deprioritize protection (recasting is fine).
  - Expensive / strategy-essential commanders → invest heavily in protection.
- Context: the pod tends to run **light removal** overall.

## Aesthetic dislikes
- **Despises Day/Night** — avoid daybound/nightbound and day-night-transform cards; don't let a deck end up caring about the day/night mechanic if it can be avoided.

## Meta-project
- Building a **full cycle of commanders, one per color / color-set**.
- Started between **Final Fantasy (FF)** and **Edge of Eternities (EoE)**, so those sets are the best-known reference points.
