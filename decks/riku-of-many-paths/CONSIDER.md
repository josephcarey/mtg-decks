# Consider next — Riku of Many Paths

Running list of cards/ideas to weigh on the next pass. Seeded from an EDHREC
reconciliation (2026-09). Nothing here is committed to the list.

## Theme reminder
Sub-theme is **modal / choose-a-mode + impulse (cast-from-exile)**. We
deliberately AVOID copy-spell and spellslinger/magecraft payoffs here — those
are reserved for Saruman. EDHREC's #1 theme for Riku is spellslinger (1040
decks); that gap is intentional, not an oversight.

Revisit only if we ever decide to blur the Riku/Saruman theme split.
