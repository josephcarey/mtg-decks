# Commander Color Cycle — Master Board (all 27 slots LOCKED)

Canonical tracker for the commander-cycle meta-project (see `PRIORITIES.md`). One NEW
commander deck per color identity, skipping 4-color. Colorless `{C}` counts. **27 slots total.**

- **Constraint — archetype diversity:** each theme lives in exactly ONE deck across the cycle.
  Kindred is a rationed theme (spent on Namor + Torgal).
- **Priorities:** no Game Changers; no non-games (infinite combo / stax / MLD / extra-turns);
  no Day/Night; mid-budget; theme-first; casual Bracket 3.
- **Workflow:** build each deck in its own fresh session, one `decks/<slug>/` folder at a time
  (`list.txt` + `notes.md` per repo conventions). Update the **Build status** column here as
  decks are completed.
